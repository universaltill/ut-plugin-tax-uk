What this does

UK VAT law (HMRC VAT Notice 709/1) treats most cold food differently depending on how a customer takes it: zero-rated when taken away, but standard-rated when eaten on the premises. This plugin applies that switch automatically at checkout — you don't need to ring up a different item or remember to change anything by hand.

How it decides

  • Takeaway order — no change. The item's own tax code (usually zero-rated) applies as normal.
  • Eat-in order — if the item's tax code is one you've configured below, its rate is switched to the standard rate for that sale. If the tax code isn't configured, nothing changes — this covers items you never want switched, like hot food and drinks, which are standard-rated regardless of eat-in or takeaway and don't need this plugin's help.
  • Dine-in/takeaway choice switched off — no change. If your till doesn't ask "eat in or take away?" at all, there is no eat-in to switch to, so every item keeps its own tax code.

Configuring which tax codes switch

Open this plugin's settings and edit eatin_standard_rate_by_tax_code — a JSON object mapping one of your shop's own tax code IDs to the standard rate you want applied for eat-in, in basis points (2000 = 20%): 

{"tax_zero": 2000}

This maps your zero-rated tax code to 20% VAT when a sale is marked eat-in. To find a tax code's ID, open Catalog, open any item using that code, and check its Tax code field — the same codes also appear in that field's suggestion list. You can list more than one tax code if your catalog uses several zero-rated codes for different categories of cold food.

Service charges and tips

The plugin also tells the till the UK's standard service-charge and tip rules. It doesn't switch a service charge on or set its rate — that stays in your own till settings.

  • Service charge — allowed. 12.5% is the usual UK rate, but the till doesn't apply it for you: the rate you configure is the one charged, and only if you've switched the service charge on.
  • VAT on a service charge — split across the sale's items at their own VAT rates (VAT Notice 709/1), not charged at one flat rate.
  • Tips — go to your staff by default, as the Employment (Allocation of Tips) Act 2023 requires.

MTD VAT return (HMRC test service only)

The plugin adds an MTD VAT Return to HMRC (sandbox) export under Data → Export. It works out Box 1 (VAT on sales) and Box 6 (sales before VAT, whole pounds) from your closed days, and sends the return to HMRC's test service. It cannot send a real return to HMRC yet.

  • Choose a date range that is exactly one of your open VAT periods. If it doesn't match, nothing is sent and the open periods are listed.
  • Close every trading day first — only closed days are counted.
  • Boxes 2, 4, 7, 8 and 9 come from your purchase records, which the till doesn't have. Enter them in the plugin settings (hmrc_box2_vat_due_acquisitions, hmrc_box4_vat_reclaimed, hmrc_box7_purchases_ex_vat, hmrc_box8_goods_supplied_ex_vat, hmrc_box9_acquisitions_ex_vat) before each return. Enter 0 for a box that doesn't apply. Boxes 3 and 5 are worked out for you.
  • The HMRC connection settings (hmrc_client_id, hmrc_client_secret, hmrc_refresh_token, hmrc_vrn) need to be set up once, outside the till, by whoever manages your HMRC access. If any setting is missing, the export tells you which one.

What this plugin does not do

  • It doesn't touch hot food/drink — those keep whatever tax code you assigned them directly in the catalog.
  • It doesn't make the eat-in/takeaway choice for you — that's the order type toggle already on the sale screen and self-order kiosk.
  • It's a simplified reading of Notice 709/1 covering the common cold-food case; unusual combinations (mixed hot/cold platters, catering, delivery) aren't modelled and may need a manual override.
  • It doesn't send real VAT returns to HMRC, and it doesn't work out Boxes 2, 4, 7, 8 or 9. Ask your accountant before relying on the figures.
